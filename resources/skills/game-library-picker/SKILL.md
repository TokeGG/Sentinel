# Game library picker

1. Read the library rows (title, last played, favourite).
2. Ask or use the time the user has; prefer short sessions for under an hour.
3. Mention any patch notes or news row for the suggestion.
4. Give two picks and why.
5. Never launch a game without the user's click.
