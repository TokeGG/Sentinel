# Meeting notes cleanup

1. Read the raw notes. Keep the original meaning; do not add decisions that were not made.
2. Write a one-paragraph summary (who met, about what, the outcome).
3. List Decisions as bullets.
4. List Action items as "- [ ] task - owner - due date". Write "owner?" or "date?" when the notes do not say.
5. List Open questions and anything marked TBD.
6. Fix spelling and expand obvious abbreviations; keep names, numbers and dates exactly as written.
