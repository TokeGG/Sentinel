# Wishlist match

1. Read the wishlist entries the user named or that are stored.
2. Match deal titles by product name and edition, not loose words.
3. Drop matches that are accessories, used items or different models.
4. List each match with price and store, cheapest first.
5. Say clearly when nothing matches.
