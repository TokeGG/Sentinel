# Startup slim down

1. Read the startup rows (name, publisher, impact).
2. Keep antivirus, drivers and input or audio helpers enabled.
3. Suggest disabling updaters and launchers the user rarely uses.
4. Explain that changes are reversible.
5. Change nothing without the user's confirm.
