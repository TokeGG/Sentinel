# Headline fact check

1. Read the headline and the first paragraphs of the article row.
2. List each factual claim the headline makes.
3. Mark a claim supported only if the body states it plainly; cite the row.
4. Note loaded words, missing numbers, or a different meaning in the body.
5. Answer with: supported / overstated / unsupported, plus one line why.
