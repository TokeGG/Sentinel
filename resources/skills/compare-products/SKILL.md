# Compare products

1. Restate which products are compared and what matters to the user (budget, size, features). Ask if unclear.
2. For each product, find: current price and shop, 3-5 key specs, average rating and number of reviews, warranty.
3. Use the same source type for every product (all from one shop, or all from the makers' pages) so numbers are comparable.
4. Build a small table: one row per product, the same columns for all. Mark unknown values as "?" rather than guessing.
5. Recommend one product for the stated needs in two sentences, and name the runner-up and why.
6. Never add to cart, buy or sign in. Mention that prices change and give the date checked.
