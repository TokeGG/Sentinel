# Story timeline

1. Pick the rows that mention the same story (names, places, key terms).
2. Sort them by published time, oldest first.
3. Write one line per row: date, what changed, source title.
4. Merge rows that repeat the same fact; keep the earliest.
5. End with what is still unknown or disputed.
