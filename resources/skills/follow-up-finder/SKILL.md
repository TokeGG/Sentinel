# Follow up finder

1. Find rows where the user sent the last message more than 5 days ago.
2. Find rows with a question to the user and no reply yet.
3. List each with sender, subject and age.
4. Draft a two-line polite follow-up for each, for review only.
5. Never send anything without the user's confirm.
