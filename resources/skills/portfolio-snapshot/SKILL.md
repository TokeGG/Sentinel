# Portfolio snapshot

1. Read the watchlist and portfolio rows (symbol, price, change, lots).
2. List the three biggest movers up and down with the cited rows.
3. Add up gain/loss per lot only from stored numbers; show the math.
4. Note if one holding is over a quarter of the total.
5. Say this is information, not financial advice.
