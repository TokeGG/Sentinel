# Privacy settings checkup

1. Ask which service or device, and let the user sign in themselves; the bot never types passwords.
2. Go through the areas in order: two-factor sign-in, connected apps, ad personalisation, location history, who can see posts/profile, data download.
3. For each setting: say what it does, its current value (as the user reports or the page shows) and the safer choice.
4. Point to the exact menu path; change a setting only when the user approves that step.
5. Suggest removing connected apps the user no longer uses.
6. End with a short list of what was changed and what was left as is.
