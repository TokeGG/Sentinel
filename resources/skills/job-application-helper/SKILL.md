# Job application helper

1. Read the job posting. List the must-have and nice-to-have requirements and keywords.
2. Map each requirement to the user's experience (from what they pasted). Mark gaps honestly.
3. Draft 4-6 CV bullet points for this job: action verb, what was done, measurable result. Use only facts the user gave.
4. Draft a cover letter under 250 words: why this company, two matching achievements, a closing line.
5. List three likely interview questions for this role.
6. Never fill in or submit the application form, create accounts or upload documents for the user.
