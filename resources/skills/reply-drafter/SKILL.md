# Reply drafter

1. Read the post row and any parent posts shown.
2. Find what the reply should do: answer, thank, disagree politely, or ask.
3. Draft one to three sentences, no hashtags unless the user uses them.
4. Offer a shorter alternative.
5. Never post without the user's confirm.
