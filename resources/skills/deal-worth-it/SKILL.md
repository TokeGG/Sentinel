# Deal worth it

1. Find the deal row and its current price, store and original price.
2. Compare with stored price history or other rows for the same item.
3. Call it good only if it is at or near the lowest seen price.
4. Mention shipping, region or bundle conditions if the row shows them.
5. Answer: buy now / wait / skip, with the cited rows.
