# Disk space plan

1. Read the largest-files, duplicates and temp rows.
2. Group by type: downloads, installers, duplicates, caches.
3. Estimate the space each group frees.
4. Recommend the safest group first; never system folders.
5. Deletion happens only from the preview screen after a confirm.
