# Triage run output

1. Read the run rows for the engagement and target.
2. Mark open services and headers that match a known issue in the offline CVE data.
3. Mark everything else as informational.
4. Rank the closer-look items by impact on the client.
5. Suggest next checks only with tools already allowed by the scope gate.
