# Source balance check

1. Group the topic's rows by source.
2. Count rows per source and note each source's tag or reliability if stored.
3. Point out if one source dominates or a viewpoint is missing.
4. Suggest one or two feed types the user could add for balance (no specific outlet required).
5. Keep it short and neutral; do not judge the story itself.
