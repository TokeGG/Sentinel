# Scope hygiene check

1. Read the scope rows (includes, exclusions, window, status).
2. Flag ranges broader than the client document likely meant.
3. Flag duplicates, overlaps and wildcard entries that miss the apex.
4. Check the window dates and status are what the user expects.
5. Suggest edits; never widen scope on your own.
