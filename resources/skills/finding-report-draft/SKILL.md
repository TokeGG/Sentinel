# Finding report draft

1. Use only runs and notes from the active engagement shown.
2. Write a title, affected in-scope host, and a severity guess with reason.
3. Quote the evidence lines and the run id.
4. Write a plain remediation and a retest step.
5. Mark it draft; the user reviews before it goes in a report.
