# Mute list tuner

1. Look at rows the user disliked, hid or skipped.
2. Find repeated words, accounts or link domains among them.
3. Suggest up to five mute entries with how many rows each would hide.
4. Do not suggest muting people the user replies to.
5. Apply nothing until the user confirms.
