# Inbox triage

1. Read sender, subject and date of each mail row (no bodies unless shown).
2. Reply now: direct questions or deadlines within 3 days.
3. Read later: newsletters and long updates.
4. Archive candidates: receipts, notifications, old threads.
5. Return three short lists with row citations; never move mail without a confirm.
