# Note summarize

1. Take the notes the user selected (or the most recent unfiled ones if none were selected).
2. Write a summary of at most five bullet points that keeps the user's own wording for names, numbers and dates.
3. Add an "Action items" list for anything phrased as a to-do, with dates when the note gives them.
4. Do not edit, move or delete the notes; offer a suggested title and folder instead.
