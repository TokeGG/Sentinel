# Draft an email reply

1. Read the email. List what it asks for (questions, decisions, dates) before writing.
2. Ask the user for anything only they know (their decision, availability) if it is not in the request.
3. Write the reply: greeting, one line acknowledging their message, answers to each question in order, the next step, sign-off.
4. Keep it short (under 150 words unless asked) and match the formality of the original.
5. Offer one alternative phrasing for any sensitive sentence (a "no", a delay, a price).
6. Output only the draft text. Never press Send or Submit; the user sends it themselves.
