# Travel planner

1. Restate destination, dates, number of travellers, budget and interests. Ask for whatever is missing.
2. Check opening days and hours of the main sights for the travel dates, and public holidays.
3. Group sights by area so each day needs little travel; keep one lighter half-day.
4. For each day: morning / afternoon / evening, the transport between places and a rough cost.
5. Add practical notes: how to get from the airport/station, a ticket or pass that saves money, booking-ahead warnings.
6. Never book, pay or sign in. Give links to the official pages used.
