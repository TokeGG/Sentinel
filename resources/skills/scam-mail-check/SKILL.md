# Scam mail check

1. Compare the display name with the real sender address and domain.
2. Look for urgency, threats, prize claims or requests for codes or passwords.
3. Check whether links point to a different domain than the claimed sender.
4. Never open attachments or links as part of the check.
5. Answer: looks fine / suspicious / very likely a scam, with the reasons.
