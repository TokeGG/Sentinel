# Summarise a page

1. If an address was given, go to it. Dismiss a cookie banner once if it covers the text.
2. Read the page text. If the article continues on another page ("Next", "Page 2"), follow at most two more pages.
3. Ignore navigation, ads, comments and "related articles".
4. Answer with: the page title, the link, then 3-6 bullet points with the main claims, numbers and dates in the page's own terms.
5. Add one line "Not covered:" if the reader would expect something the page does not say.
6. Never invent facts that are not on the page. Never sign in or accept paywall offers; if a paywall hides the text, say so.
