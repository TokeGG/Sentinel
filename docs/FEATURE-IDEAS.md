# Feature ideas (round 5, 40 ideas by panel)

Proposals only; nothing here is built. Same principles as the backlog: local-first, no hosted AI,
nothing in the background without opt-in, secrets only in the keychain, Lab always engagement-gated.

## News (incl. Congress, Weather)
1. Story follow: pin a story and get a moon when a new row matches its key terms.
2. "Explain like I'm new" Ask preset that pulls background from Wikipedia (data source) before answering.
3. Weekly topic report: the Ask bar writes a one-page summary per followed topic, saved to Notes.
4. Weather-aware calendar hints: rain alerts next to outdoor calendar events (Open-Meteo, on demand).
5. Bill change diff: side-by-side text diff of a followed bill's versions.

## Deals
6. Price target per wishlist item with a "reached" moon (checked only on refresh).
7. Store trust notes: per-store knowledge entries (returns, shipping) fed to the Ask bar.
8. Bundle checker: compares a bundle's price with the sum of its items' CheapShark prices.

## Finance
9. Dividend calendar from lots + manually entered pay dates.
10. Budget drift chart: spend vs. budget per category per week.
11. Filing watcher: list new SEC filings for watchlist tickers on refresh (EDGAR data source).
12. What-if: rebalance preview to target weights, never placing orders.

## Mail
13. Sender profiles: per-sender stats (volume, last reply) and one-click mute rule (preview first).
14. Scam score badge from the scam-mail-check skill + RDAP domain age, shown on suspicious rows.
15. Reply templates library shared with Notes snippets.
16. Newsletter digest: fold all unread newsletters into one Ask summary.

## Media (YouTube, Media, Games)
17. Time budget: "I have 40 minutes" filter across watch-later and episodes.
18. Game backlog board (playing / next / done) with PCGamingWiki fix notes per game.
19. Podcast chapters from enclosures (where the feed provides them).
20. Release radar: upcoming episodes and game releases in one week view.

## Social / Chat / Discord
21. Draft queue: compose posts offline, post later only by hand.
22. Thread reader mode: flatten a long thread into one scroll with the thread-summary skill.
23. Chat clip notes: mark a chat moment and store it with the stream timestamp.
24. Cross-post preview: one draft, per-platform length/format check before posting.

## Dev (GitHub, Skills, Bot)
25. Release notes builder from merged PRs (changelog-writer skill), copied to the clipboard.
26. Dependency watch: npm/OSV lookups for a cloned repo's package.json on demand.
27. Bot workflow marketplace export/import as signed JSON files.
28. Bot dry-run diff: show page snapshots before/after each step of a dry run.
29. Skill tester: run a SKILL.md against saved example questions and compare answers.

## System (PC Care, Home Network, Backup, File search)
30. End-of-life report: installed Windows/runtime versions vs. endoflife.date.
31. Patch Tuesday card: MSRC monthly release with installed-update status.
32. Device notes: per-device manual, warranty date and purchase info.
33. Backup restore drill: monthly opt-in reminder to test-restore one file into a temp folder.
34. Saved file searches with result-count moons (manual refresh).

## Productivity (Notes, Calendar, Clipboard, Browser)
35. Meeting prep: Ask bar gathers notes, mails and tasks mentioning an event's attendees.
36. Holiday overlay from Nager.Date for chosen countries.
37. Reading list from the browser with offline text copies in the Notes vault.
38. Clipboard to task: one click turns a copied line into a Calendar task.

## Lab (always through the scope gate)
39. Report readiness check: lists findings missing evidence, severity or retest before export.
40. KEV/NVD enrichment of findings: adds CVSS and KEV status from enabled data sources to the report draft.
